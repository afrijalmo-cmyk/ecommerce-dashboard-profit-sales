# 📊 E-Commerce Sales & Profit Dashboard | $8M Analysis

## 📌 Overview
Interactive Dashboard untuk analisis 51,275 transaksi E-Commerce. Project ini fokus menjawab kenapa Profit hanya $3.7M dari Sales $8M dan strategi discount yang tidak efektif.

**Dataset:** 51,275 rows (after cleaning dari 51,282)
**Tools:** Python (Data Prep), Excel / Looker Studio (Visualization)
**Role:** APRIJAL, S.E - Certified Data Analyst (BNSP - DQLab)

## 📄 Project File
- `Proyek Alkemis.pdf` - Full business report & dashboard design

## 💡 Key Insights (Dari Dashboard)
1.  **Total Sales: $8.01M | Total Profit: $3.7M | Margin: 46%**
2.  **Lowest Profit Product:** Mixer/Juicer hanya $0.5 profit
3.  **Korelasi:** Sales-Profit 0.92 (Sangat Kuat), Discount-Profit -0.12 (Diskon menurunkan profit!)
4.  **Anomali:** Ditemukan Shipping Days -106 hari (Data Error) - Sudah dibersihkan
5.  **Kategori Bermasalah:** Electronics, Sales tinggi tapi profit hampir 0

## 🎯 Rekomendasi Bisnis
- Audit strategi diskon untuk kategori Electronics
- Review pricing untuk produk Mixer/Juicer
- Perbaiki SOP input Ship Date untuk cegah anomali -106
